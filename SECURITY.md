# Security

Please don't open a public issue for a security problem. Report it privately with **Report a
vulnerability** on this repository's
[Security tab](https://github.com/CatDogBark/amahi-kai-apps/security/advisories/new), or email
catdogbark@pm.me.

An app whose manifest gives it more than it should, or an image that isn't what it claims to be,
belongs here. A problem in Amahi-kai itself goes to
[Amahi-kai's Security tab](https://github.com/CatDogBark/Amahi-kai/security/advisories/new).
